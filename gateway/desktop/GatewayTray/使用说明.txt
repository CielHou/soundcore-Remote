声核网关（Windows 托盘版）使用说明
====================================
版本 1.0.0 · 作者：Ciel · 微信：Apple_Hkc

一、这是什么
------------
手机上的「声核遥控」无法直接连接声核的本机接口（声核只允许本机程序访问）。
本程序在电脑上做「翻译层」：电脑本机连接声核，手机通过局域网连到本程序，
从而实现手机控制声核的通道（静音 / 音量 / A-B 切换）。

二、安装位置与目录内容
----------------------
安装方式：双击「声核网关安装程序.exe」，按提示点「安装」即可（默认不需要管理员权限）。
安装程序会自动完成：释放程序文件 → 创建桌面和开始菜单快捷方式 → 设置开机自动运行
→ 写入「设置 → 应用」里的卸载项。升级时重新运行安装程序即可，配置和凭证都会保留，
手机连接地址不会改变。

如果旧版网关还在以管理员身份运行，普通权限覆盖不了它的文件，安装程序会自动申请一次
管理员权限（Windows 弹出「你要允许此应用对你的设备进行更改吗」时点「是」即可）。

程序目录：%LOCALAPPDATA%\AudcoreGateway
（完整路径一般是 C:\Users\<你的用户名>\AppData\Local\AudcoreGateway）

声核网关.exe        托盘主程序（双击启动，也会打开控制面板窗口）
gateway-core.exe    网关核心（由托盘自动拉起，不要手动双击）
gateway.config.json 配置（端口 18533 / 状态页 18534）
gateway.log         运行日志（托盘菜单「查看运行日志」也能看）
卸载声核网关.exe    卸载程序（安装时自动放置，一般用不到）
版本.txt            版本与打包时间
使用说明.txt        本文件
.state\             凭证目录
  audcore-token.txt 电脑连接声核用的令牌（不要外传）
  client-token.txt  手机连接网关用的令牌（手机地址里用）

三、启动方式
------------
方式一：双击桌面「声核网关」图标。
方式二：已加入开机启动项，登录 Windows 后会自动在托盘运行。
启动后托盘（任务栏右下角）会出现蓝紫色耳机图标；声核打开着的话，
网关会自动连上声核，托盘提示会显示「声核已连接 · 手机 N 台」。

四、托盘菜单
------------
打开控制面板      显示带按钮的窗口（也可直接双击托盘图标）
打开状态页面      在浏览器查看双向连接详情、通道列表、手机连接地址
复制手机连接地址  直接复制 ws://...?token=... 形式地址，粘到手机 App 的服务器地址
查看运行日志      实时日志窗口（排查连接问题用）
重启网关          重启网关核心（改了大量声核设置后可用）
跟随声核自动启停  默认开启：声核开 → 网关自动开；声核关 → 网关自动关
开机自动运行      默认已开启（对应开始菜单启动项），可在此关闭
退出声核网关      停止网关并退出托盘程序

五、手机怎么连
--------------
1. 手机和电脑连同一个 Wi-Fi / 同一个局域网；
2. 托盘菜单点「复制手机连接地址」（或控制面板里的同名按钮）；
3. 手机 App → 设置 → 服务器地址，粘贴该地址（形如
   ws://192.168.31.15:18533/api/v1?token=xxxxxxxx）；
4. 回到连接页点「连接」，成功后自动进入通道界面。

六、常见问题
------------
1) 手机连接超时
   - 确认电脑和手机在同一网段（例如都是 192.168.31.x）；
   - 首次运行若弹出 Windows 防火墙提示，请选择「允许访问」；
   - 也可用管理员 PowerShell 执行一次：
     netsh advfirewall firewall add rule name="AudcoreGateway 18533" ^
       dir=in action=allow protocol=TCP localport=18533 profile=private
   - 部分路由器的「AP 隔离 / 访客网络」会阻止设备互访，需要关闭。

2) 托盘里看不到图标
   - Windows 11 默认把新程序的图标收进 ^ 折叠区：点 ^ 展开查找耳机图标，
     或右键任务栏 → 任务栏设置 → 其他系统托盘图标 → 打开「声核网关」；
   - 若展开后也没有：请确认程序是从上面的「二、安装位置」目录运行的。
     把程序放在受限目录（例如带特殊权限的文件夹）里时，Windows 会拒绝
     注册托盘图标；此时双击桌面图标仍会打开控制面板窗口，功能不受影响。

3) 托盘显示「声核未授权」
   - 打开声核 → 设置 → API 连接管理，确认「本地 API」是开启状态；
   - 若声核里出现授权弹窗，点「允许」；
   - 实在不行：关闭声核再打开，托盘会自动重启网关并重新授权。

4) 想让手机地址固定不变
   - 网关令牌固定保存在 .state\client-token.txt，重启不会变（已经固定）。
   - 只有换网卡 / 换路由器导致电脑 IP 变化时，地址前面的 IP 才会变。

5) 端口被占用 / 一直重启
   - 说明有另一个网关实例在跑：任务管理器结束所有 gateway-core.exe，
     再在托盘菜单点「重启网关」。

七、安全提示
------------
- gateway-core 只监听局域网，且手机必须带 token 才能认证；
- 声核令牌只在电脑本地 .state 目录，不会发给手机；
- 不要把 client-token.txt 发给别人；不想让某人连接，删掉该文件后重启网关
  会生成新令牌（手机端需重新粘贴新地址）。

八、控制面板窗口
----------------
双击桌面图标（或托盘菜单「打开控制面板」）会打开窗口，里面有：
- 声核连接状态、手机连接数量、当前可用的手机连接地址；
- 「打开状态页面」「复制手机连接地址」「刷新状态」「运行日志」
  「最小化到托盘」「退出网关」按钮。

点窗口右上角 × 只是把窗口收进托盘，网关继续工作；再双击桌面图标就能重新打开。

窗口里还有「展示二维码」：点一下会在按钮下方弹出扫码框，手机 App「连接」页点「扫码连接」
直接扫这个码即可，不用手动输入地址；再点一次「隐藏二维码」收起。
窗口底部显示版本、作者与联系方式。

九、卸载
--------
方式一：Windows「设置 → 应用 → 已安装的应用」里找到「声核网关」→ 卸载；
方式二：开始菜单 → 声核网关 → 卸载声核网关；
方式三：运行安装目录下的「卸载声核网关.exe」。

卸载会停止网关、删除程序文件、桌面/开始菜单快捷方式和开机启动项。
授权凭证目录 .state 会保留（重装后手机连接地址不变）；彻底清除请卸载后手动删除
%LOCALAPPDATA%\AudcoreGateway\.state。

十、版本说明
------------
1.0.0（2026-10-22）
- 首个正式交付版：手机 App、电脑网关、安装程序统一版本号 1.0.0。
- 安装包为单文件，双击即可安装，全程普通用户权限、不再请求管理员权限（UAC）。
- 全新应用图标：安装程序、桌面/开始菜单快捷方式、托盘窗口、手机 App 统一使用。
- 控制面板新增「展示二维码」：按需弹出扫码框，手机扫码即可连接；手机连上后不会自动收起。
- 状态网页不再放二维码（避免网页二维码渲染异常），二维码只在电脑窗口里显示。
- 关于信息：安装程序、控制面板窗口、手机 App「设置」页都显示 1.0.0 · 作者 Ciel · 微信 Apple_Hkc。

1.2.0（2026-10-21）
- 状态页和控制面板现在不需要手机连接也能显示通道状态：网关自己订阅声核通道。
- 自动识别真正连网的网卡（通过系统选路探测），多个网卡/虚拟网卡时默认选中正确的地址，
  不会再默认挑到网络共享（192.168.137.x）或虚拟网卡。
- 控制面板新增「刷新状态」按钮；打开状态页不再受以管理员身份运行的 Edge 干扰。

1.1.0
- 提供安装包（桌面/开始菜单快捷方式、开机自启、可在系统里卸载）。
- 托盘程序内置控制面板；关闭窗口只收进托盘，双击图标或再运行一次程序即可重新打开。
- 托盘图标不显示时，多半被 Win11 收进任务栏右下角的 ^ 折叠区，可在「任务栏设置 → 其他系统托盘图标」里打开。
